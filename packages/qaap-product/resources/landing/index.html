Questions, answered.

What is Qaap?

A cloud workspace where AI coding agents work on your GitHub repositories. You give a task, the agent edits the code in its own isolated workspace, and you review the diff, try the app and merge the pull request — on desktop or on your phone.

Which agents can I use?

Claude Code, Codex, Gemini (Antigravity CLI), GitHub Copilot CLI, Cursor Agent, OpenCode, Grok Build, Qwen Code, Kimi CLI, Pi, OpenClaw and Qaap's own QAIQ. You can switch agents between tasks.

Do I need my own AI subscription or API key?

Yes. Qaap is bring-your-own-AI: sign in to the agents with the plans you already pay for, or add an API key. Your plan covers the workspace — compute, storage and parallel agents — never the tokens.

Is my code safe?

Each account runs in its own isolated container, agents only see the repositories you connect, and commands that need it ask for your approval first. You can revoke GitHub access at any time.

Does it work on my phone?

Yes — Qaap is designed for the phone first. Open qaaq.dev in your mobile browser and add it to your home screen to use it like an app.

How does billing work?

Choose Starter or Pro, pay monthly through a secure hosted checkout, and change or cancel your plan anytime from Settings → Plan.
