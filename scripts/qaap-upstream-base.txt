# The fork syncs upstream Theia by CONTENT (its history is disjoint from upstream's), so drift is
# measured as a content diff against the upstream commit the fork was last aligned to. The tracking

# in-progress sync); comparing against the moved ref then inflates drift with pure fork-lag for
# every file upstream changed since. This file pins the base to the actually-adopted commit so the
# drift number stays meaningful.

# override with QAAP_DIFF_BASE=<ref>.
